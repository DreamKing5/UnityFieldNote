# 検証報告

## 結論と範囲

**ローカルの実ブラウザ統合テスト：16項目PASS。** 新規追加後の独立した別セッションでの再表示、全体／ジャンル内の並べ替えの保存・再表示を実行した。

**本物のSupabaseプロジェクトへの接続、PostgreSQL上でのschema.sqlの実行、実際のRLS・権限ポリシーの動作、GitHub Pagesへのデプロイは未実施。** この納品環境には対象プロジェクトの設定・認証がないため、これらを検証済みとはしていない。SQLについては設計とソースレビューまでであり、実DB上の実行検証ではない。

本番公開前にSETUP.mdの最終確認と、同梱のsecurity-smoke.sqlを実施すること。

## 使用環境

- 実行日：2026-09-05
- Chromium、Playwright 1.45.0、Node.js 24、Python 3、SQLite
- デスクトップ：1440 × 980
- スマートフォン相当：390 × 844（エミュレーション。実機iOS Safariではない）
- セッションAとB：別々のBrowserContext。Cookieやブラウザストレージを共有しない。
- 保存先：ループバックHTTPサーバー上のSQLiteファイル。ブラウザ内保存ではない。
- tests/server.pyはSupabase Auth / RPCの**テスト代替物**。実際のPostgreSQLやRLSを再現・証明するものではない。

### 追加の保存確認

ローカルサーバープロセスが停止した後、--resetを付けずに再起動し、revision=10・216件のデータがSQLiteに残っていることを確認。その後、最終の16項目テストを再実行してPASSした。

### 画面確認

一覧、詳細、入力、Markdownプレビュー、整理、ログイン、データ入出力、未設定、検索0件、更新競合、モバイルメニューの画像を確認。文字化けしたアイコンをSVG/CSSへ置き換え、デスクトップと390px幅で再確認。横方向のページはみ出しなし。カード概要の2行省略、縦スクロール、固定追加ボタンと一時的な通知の重なりは意図した仕様。

同梱のscreenshots/は**架空のサンプル／検証データ**を表示したもので、実際のNotionからの移行結果ではない。

### 軽量化の確認

- site/の全配信ファイル：182,062 bytes（ライセンス等も含む実測合計）。
- 各ファイルを個別にgzip圧縮した参考合計：64,473 bytes。実際の配信転送量・キャッシュ・応答時間を意味しない。
- CDN・外部Webフォント・外部画像・フレームワーク・ビルド工程なし。
- 通常のDOMは最大24カード。整理モードは最大40行。
- 通常一覧APIのレスポンスにbodyフィールドがないことを検証。
- 全件書き出しは200件単位で取得し、216件を欠落なく出力することを検証。
